# Password Manager
A command-line password manager built in Python that securely stores account 
credentials by website and username. This project was create to practice working 
with JSON files, program organization, user authentication, and modular Python design.

## Features
- Master password authentication
- Add, update, search, and delete saved passwords
- Store multiple accounts for the same website
- Search all websites using a username
- Secure password generation using Python's secrets module
- Automatic JSON data storage
- Automatically removes empty websites when the last account is deleted

## Technologies Used
- Python
- JSON
- json
- secrets
- string

## Installation / How to Run
1) Clone the repository
2) Make sure Python 3 is installed
3) Run
    -> python main.py

⭐️On the first launch, you'll be prompted to create a master password. 
  This password is required each time the program is opened
